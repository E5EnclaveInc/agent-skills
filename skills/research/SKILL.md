# Research

> **Attribution:** Adapted from mattpocock/skills (MIT). Upstream is canonical; this adaptation adds E5's curation and promotion-gate framing.
>
> Method only; no code or text copied. See `LICENSE` for the upstream MIT license notice.

Answer from primary sources, cited. Summaries of summaries are not sources.

## Method

1. State the question and what would count as an answer.
2. Read the primary source: the docs, the code, the spec, the paper —
   not the blog post about it.
3. Cite what you claim: source name and the exact location (section,
   line, version).
4. Separate what the source says from what you infer. Label each.

## Output

The answer, the citations, and the inference labels. If the sources
conflict, report the conflict instead of picking a winner silently.
