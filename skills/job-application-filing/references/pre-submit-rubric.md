# Pre-Submit Evaluation Rubric

Run this checklist immediately before ANY submit steer. Every box must be checked.

1. **Posting verified live** on the official employer/careers site this session — not an aggregator mirror, not a cached page.
2. **Remote-only confirmed** in the posting text (strict: no hybrid, no office-proximity radius, no relocation requirement).
3. **Exact role match** — the filed role is the approved role, no substitution.
4. **Still accepting applications** — no "closed", "no longer accepting", or expired-date signals.
5. **All required fields truthful** — every entry traces to the canonical answers or the applicant's verified record. Nothing invented, nothing "close enough".
6. **Documents attached and verified** — résumé PDF and (where the form has a field) cover letter PDF show as successfully uploaded in the portal UI. Filenames match the built packages.
7. **PDFs clean** — text-extractable, no "deltas", no working-note trailers, no truncated sections (no bare `---` in sources).
8. **Compensation field handled** per the applicant's documented compensation strategy in the canonical answers (e.g. required → posted-range midpoint; optional → blank/negotiable).
9. **Approval in force** — the filing is inside a standing pre-approval window or has explicit per-target approval.
10. **Confirmation capture ready** — know what the confirmation screen looks like for this ATS so you can record the exact text and reference number.

If any box fails: do NOT submit. Park, log, and report the blocker.
