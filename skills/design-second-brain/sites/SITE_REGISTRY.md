# Site Design-Language Registry — TEMPLATE

One entry per property. Status discipline: **VERIFIED** (opened live this
cycle and confirmed) or **UNVERIFIED** (known to exist; design language not
yet confirmed against the live asset). Never mark a property VERIFIED from
memory — open the live asset first.

## How to add a property
1. Open the live site. Record only what the live asset shows.
2. Capture: hosting/deploy path, the canonical visual reference page, the
   design language (register, palette, type), form setup, and active
   directions (campaigns, pending launches).
3. Date the verification. Stale entries get re-verified before any redesign
   work cites them.
