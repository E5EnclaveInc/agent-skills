# Handoff

> **Attribution:** Adapted from mattpocock/skills (MIT). Upstream is canonical; this adaptation adds E5's curation and promotion-gate framing.
>
> Method only; no code or text copied. See `LICENSE` for the upstream MIT license notice.

Continuity is a document, not a memory.

## The handoff contains

1. What the session was trying to do, in one paragraph.
2. What is done — with evidence (commits, test runs, files).
3. What is next — the concrete next step, not a vague direction.
4. Open questions and who owns them.
5. Traps: what was tried and failed, so it is not retried blindly.

## Rules

- Facts, not vibes: every "done" carries its receipt.
- The next agent should be productive in minutes, not hours.
- Nothing meaningful lives only in chat — the handoff is the transfer.
