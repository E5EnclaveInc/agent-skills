# To Questionnaire

> **Attribution:** Adapted from mattpocock/skills (MIT). Upstream is canonical; this adaptation adds E5's curation and promotion-gate framing.
>
> Method only; no code or text copied. See `LICENSE` for the upstream MIT license notice.

Open questions become answerable when they are written for the person
who holds the answers.

## Method

1. List the open questions — each one concrete, each with why the answer
   matters (what it unblocks).
2. For each: the context the answerer needs, and what a good answer
   looks like (a decision, a number, a name — not an essay).
3. Order by dependency: what must be answered first.

## Output

The questionnaire document. Send it; when answers return, they go
straight into the spec or decision log — no re-asking.
