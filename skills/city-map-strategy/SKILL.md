# City Map Strategy

## Purpose
Turn a quarter's marketing into an executable map: anchor the WHY, set at most 3
destinations, draw signal lines from the why to each destination, name the
passengers, pick formats as stops, run a timetable — always working backwards
from goals, never content-first.

## Workflow
1. Anchor Grand Central. Write the WHY in one sentence. Every line routes through it.
2. Set destinations — max 3. The quarter's goals; each destination gets its own
   content types AND its own metric.
3. Draw the lines. For each destination, define the SIGNAL carrying people from the
   why to the destination. Work backwards: goal → signal → content. Never start
   with "what should we post."
4. Name the passengers. The specific audience riding each line — granular, in
   their language, where they actually talk.
5. Set the stops. The content formats that keep passengers on the line. Different
   destinations can be served by different formats.
6. Set the timetable. Cadence per line (e.g., 2 posts/week per line).
7. Balance the map. Run multiple formats simultaneously, each judged on its own
   metric. Balance growth vs loyalty/retention content — the ratio is individual
   and can be platform-dependent.
8. Scale check. One map can carry many ventures: different goals and audiences get
   different lines and formats, not the same content repackaged.
9. Review monthly; redo quarterly.

```

└── D3 goal → metric: ____ | signal: ____ | passengers: ____ | stops: ____ | timetable: ____
```
A full worked example (a fictional playbook brand's quarter) is in
`references/worked-example.md`.

## Output Contract
A one-page city map: Grand Central (the why), ≤3 destinations with their own
metrics, one line per destination (signal → passengers → stops → timetable), a
balance note (growth vs retention), and the next review date.

## Operating Rules
1. Max 3 destinations per quarter. A fourth goal means one of them wasn't a goal.
2. One metric per destination, committed before the quarter starts.
3. Backward chaining only. Any content proposed before its destination, signal,
   and passenger are set gets rejected.
4. No shared metrics across lines — each format is judged on its own.
5. Redo the map quarterly; review monthly.
