# Retro

> **Attribution:** Adapted from mattpocock/skills (MIT). Upstream is canonical; this adaptation adds E5's curation and promotion-gate framing.
>
> Method only; no code or text copied. See `LICENSE` for the upstream MIT license notice.

After the work, improve the ground it stood on.

## Method

1. What slowed the session down? Name the friction precisely.
2. What was re-derived that should have been written down?
3. What check was missing that would have caught the bug earlier?

## Output

Concrete proposals, each with the file it changes and the exact edit —
never vague "improve docs" wishes. Proposals that change behavior or
policy are staged for a decision, not applied silently.
