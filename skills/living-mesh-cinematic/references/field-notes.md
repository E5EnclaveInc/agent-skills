# Field notes — B2B IT-services cinematic visuals (Scout recon, 2026-09-18)

Surveyed Kyndryl, Zayo, Lumen, Rackspace, Cloudflare, CDW (fetched page text +
media assets; canvas/WebGL not confirmable from text extraction — absence of
observed sims is not proof of absence).

## The field is quiet — and decorative

Nobody observed runs canvas network sims or scroll-driven cinematic sequences
on marketing pages. The genre's motion vocabulary: ambient background-video
loops, logo walls, count-up stat bands, click-to-play YouTube explainers,
static dashboard photography. All decoration; nothing teaches. The one
exception: Lumen's interactive edge-location map (teaches where capacity
lives — the only observed visual that answers a question).

## Cliché-avoid list

- Ambient background-video loops (atmosphere, teaches zero).
- Count-up stat bands (scale theater).
- Logo walls ("Trusted By the Brands You Trust").
- Click-to-play marketing explainers.
- Engineer-staring-at-dashboard stock photos.
- Generic workplace lifestyle photography.

## Stealable principles

1. **Make the visual answer a question** (where / what state / what next) —
   Lumen's capacity-map principle. A rollout board should read as waves and
   states, not a pretty network.
2. **Consoles replay, not pose.** A scrubable replay (playhead, event log,
   state changes) beats a dashboard photo.
3. **Failure is the untold visual story.** Zero observed failover/rerouting
   visualizations in the field — the node-drop → reroute → recovery loop is
   the differentiator; protect and extend it.
4. **Stat bands are narrative or cut.** Numbers in motion must tie to the
   visual's story (nodes healed, waves complete) — never orphan count-ups.
5. **Ambient motion must encode state.** Pulses = traffic, breathing = health.
   Any loop that doesn't encode a state is wallpaper — cut it.

## Honesty / accessibility moat

- "Simulated" labeling: zero hits across surveyed pages. Honest SIMULATED
  labeling is a genuine differentiator — extend per-visual
  (SIMULATED ROLLOUT, SIMULATED CUTOVER).
- Reduced-motion parity: nobody advertises it. Keep it, document it publicly
  as a pattern.

## Standing rule (Nova+Aria, war-room canon)

**Three motion postures max per page** — e.g. hero ambient / board film /
scrubber console. No two alike, no motion soup. A fourth loop is a design
smell; defer or cut.
