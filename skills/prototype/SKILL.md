# Prototype

> **Attribution:** Adapted from mattpocock/skills (MIT). Upstream is canonical; this adaptation adds E5's curation and promotion-gate framing.
>
> Method only; no code or text copied. See `LICENSE` for the upstream MIT license notice.

Some questions only yield to code. Write the smallest program that answers
the question — then delete it.

## Rules

1. State the question in one sentence before writing anything.
2. Timebox it. If the prototype grows past the question, stop and
   re-ask the question.
3. The prototype proves or kills an approach; it never becomes the
   implementation. Delete it when the question is answered.
4. Record the answer and the evidence in one paragraph for the spec.

## Never

Ship prototype code, or let "temporary" become "load-bearing."
