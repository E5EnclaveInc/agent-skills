# Wait What

> **Attribution:** Adapted from mattpocock/skills (MIT). Upstream is canonical; this adaptation adds E5's curation and promotion-gate framing.
>
> Method only; no code or text copied. See `LICENSE` for the upstream MIT license notice.

When the explanation outruns the understanding, stop and re-ask.

## The move

"Say that again in plain English" — no jargon, no assumed context, one
idea at a time. If the plain version still doesn't land, the agent
reaches for a concrete example before trying new words.

## The rule underneath

An explanation the listener cannot restate is not an explanation. The
agent keeps simplifying until the listener can say it back.
