# Teach

> **Attribution:** Adapted from mattpocock/skills (MIT). Upstream is canonical; this adaptation adds E5's curation and promotion-gate framing.
>
> Method only; no code or text copied. See `LICENSE` for the upstream MIT license notice.

Teaching compounds when each session builds on the last.

## Method

1. Establish the current level: what is already known, in the learner's
   own words.
2. One concept per session, anchored to something the learner already
   knows.
3. End each session with: what was learned, what is still fuzzy, and
   what comes next.

## Rules

- Never lecture past the fuzzy point — confusion compounds faster than
  knowledge.
- Examples before abstractions, always.
- The learner's questions set the pace, not the curriculum.
