# Grill Me

> **Attribution:** Adapted from mattpocock/skills (MIT). Upstream is canonical; this adaptation adds E5's curation and promotion-gate framing.
>
> Method only; no code or text copied. See `LICENSE` for the upstream MIT license notice.

An idea becomes committable when it survives questions.

## Method

The agent interviews you about the idea, one question at a time:

1. What changes for the user, concretely?
2. What are you explicitly not doing?
3. What is the riskiest assumption, and how would you test it?
4. Who decides the open questions?

Short answers are fine. "I don't know" is a valid answer — it becomes an
open question with an owner.

## Output

The aligned idea: goal, non-goals, riskiest assumption, open questions.
Feeds to-spec.
